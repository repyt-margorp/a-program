### Assessment

Agent initial boundary choice: ordinary admission and actual existing classifier
views for a Nat-to-Bool predicate and a List-filter consumer justify a bounded
combination of existing representations and borrowed pure-total inputs. Require
explicit invalid-result/output/arena rollback behavior and actual source/Core/C
agreement. Old unary/binary profiles keep all their refusals.
Native Acc/QuickSort, indexed/callable recursive fields, ownership escape and
higher Identity remain unfinished. Route any concrete shared-owner view/admission
need through Root; do not extend producer/schema or build a private checker.

After the actual view result, agent bounded implementation decision: add a distinct
`predicate_native_direct_v1` / `c_predicate_native_v1` profile. Callback domains
must be the same already selected Nat32 representation, arity one/two; the pure
TOTAL result must be an already selected two-constructor nullary enum. Do not
assume constructor names/order or admit indexed/callable recursive fields. Borrow
code/context synchronously and emit a signature using uint32 magnitudes and the
selected enum struct. Reject null code and invalid returned enum tags with status
2, preserving output and rolling back only the failing call's new allocations.
Use existing depth/allocation/Nat32 and finite List validation/copy contracts.
This is target metadata only, with no source erasure or new foreign typing proof.

Agent corrections from reproduced target failures: include the new native profile
in the existing shared helper symbol policy; include domain/result alias lengths
in callback names/guards so underscore-containing pairs remain distinct. These
are local ABI corrections before publication, without producer/schema changes.
Core comparisons use admitted `keep`/`less_equal` callbacks and existing Core
constructors after emission. A base-five fingerprint uniquely identifies tested
Lists of length at most four with values 0..2; it establishes their selected
sequence, not unbounded source/native completeness. Larger C-client cases and
uint32 extrema are separate target controls. Caller code/interpretation/purity,
totality, readable storage and synchronous lifetime remain preconditions.
SAN covers clients/source bodies; backend/producer/Core and other products stay
O2. Shared malloc injection is excluded; capacity/depth/rollback controls remain.

Root operational storage receipt: tmpfs ENOSPC affected other lanes. Use owned
disk-backed outputs/compiler TMPDIR for this private probe, retain initial failures,
and perform no shared cleanup or comparative workload. Focused correctness is serial.
