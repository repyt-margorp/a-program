Agent chose a separate opt-in profile to preserve old ABI/refusal contracts.

result alias lengths preserve distinct enum names. Target status transport is
private, not a Source effect or foreign error protocol. Readable initialized
immutable storage, output nonoverlap, provider purity/totality/source interpretation
and synchronous code/context lifetime remain caller preconditions. Validation does
not authenticate arbitrary pointers or foreign code. Existing arena depth256 and
allocation/capacity/rollback contracts persist.

scalar result, returned closure, effect, callable recursive identity, missing enum,

accepted adoption remain open. Existing source-semantic Acc need stays routed
