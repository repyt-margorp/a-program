# Actual Acc Down Action Candidate

This is executable, hand-authored C for the three inspected `accessibleSucc`
LT branches of the admitted Acc QuickSort. It composes with the exact C36-C41
source-generated clause, partition, append, Nat accessibility, comparison,
measurement and outer-call bodies. It is not generated action lowering or a
general Identity implementation. The original algorithm and its two folded-down
calls remain unchanged.

`actions.c` keeps the captured original Acc, parameter and raw down separate from
the folded IH. `gd_down` follows the actual source branches:

- step: right-transport a quoted Acc descriptor, then force its retained action;
- weakenRight: left-transport the prior LT into the original down domain, then
  invoke original raw down;
- lift: left-transport the prior LT, then force the folded IH, which first obtains
  child Acc from original down and constructs its successor accessibility.

The private refinement stores the nominal matched LT edge, two branch endpoints,
original captured proof and source-map cardinality. It does not serialize the
source context maps or prove arbitrary witness/action equivalence. An acted LT
retains its original constructor fields/value and refinement; an acted Acc has a
distinct callback/context retaining its original Acc. Quote construction does
not allocate or invoke down/IH. The callback acts its LT argument before entering
the original domain. These are bounded target representation choices, not new
source checking or erasure rules.

`inspect.c` reads existing owned typed Identity fields and boundary inputs from
the current accepted source. It follows origin wrappers to the direct formation;
it neither evaluates nor advances a query during inspection. This readonly
inspection is evidence for the manual correspondence, not an automatic generator.

Run the focused ordinary C clients with already qualified parent products:

```sh
sh src/prototype/c_backend/acc_down/check.sh POINTER IMAGE C41_PRODUCTS CORE_ORACLE OUTPUT
```

`IMAGE` imports the actual provider through the sealed C41 fixture. `C41_PRODUCTS`
contains accessibility/comparison/partition/append/clause/measure `.inc` files.
The resulting clients link only their C composition and the C library. `support.c`
selects this successor candidate while preserving the parent generated bytes and
existing private `gs_sort` declaration. Set `CLIENT_CFLAGS` for an instrumented
client/source build; the reused pointer/Core tools are separately pinned O2 tools.
