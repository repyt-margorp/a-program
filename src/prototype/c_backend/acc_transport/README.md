# Actual Acc Map Retention

This bounded candidate extends the readable actual Acc QuickSort module's manual
action layer with source-derived ordered map descriptors and complete target image
vectors for its three successor branches. It keeps the original source algorithm,
both folded-down calls, indices, partition, captures and public private-candidate
`gs_sort` signature. General main-native indexed/callable Acc still refuses4.

The readonly emitter borrows existing admitted typed fields, direct boundary
inputs, every ordered map image and both path binders. Existing source owner
receipts authorize selection; this reader supplies no typing, normalization or
new admission. Closed binder/Nat-successor images are represented; other shapes
refuse. Descriptive context sharing/distinction becomes distinct target tokens,
not checked Scope certificates or complete source context-declaration semantics.
There is no new producer field, .a/schema, upstream checker or source erasure.

Each runtime action retains its full captured frame, both image vectors, paths,
nominal LT edge and original value. Original down and folded IH remain separate;
paths with equal Nat endpoints retain separate binder slots. Target validation
rejects substituted context tokens, changed images, lost nominal paths and altered
captures. This is a closed representation contract, not a source equality check.
The interpretation of transport itself remains manual; full Scope/action/general
source-equivalence correspondence is still unproved.

`pack.py` regenerates a standalone ordinary C module from the sealed C45 source
bodies, the pinned new descriptor and explicitly manual target runtime. It does
not act as a generalized compiler. Generated output must not be hand-edited.
`check.sh` exercises source/object/archive clients, actual source output, retained
Core cases, all three action branches, resource/rollback/depth controls and explicit
unsupported selectors/changed products. Instrumentation of the entire candidate
and clients is separate from the reused O2 pointer/Core inputs.

Borrowed immutable code/context/data, nonoverlap, Nat32/depth256/node65536 and
private statuses1-6 persist. Retaining full vectors enlarges each action allocation
and stack record without changing the node-count ceiling; costs are unmeasured.
Overflow guards are inspected, not exercised; finite SAN cannot establish general
source equivalence or invalid foreign-pointer safety. No accepted adoption/full
#61/Goal completion follows. Historical C32-C46 submitted snapshots stay exact.
