# Actual Acc Down Branch Emission

This private source-specific emitter derives the admitted `accessibleSucc` down
branch sequencing. It emits C calls for right transport followed by force,
left transport followed by original raw down, and left transport followed by
folded IH. It reads the actual branch expressions, captured binders and owned
transport direction/boundary inputs. The sorting algorithm remains the source
Acc Fold with actual partition, two callable recursive results and pivot/append.

The emitted branches use the **manual bounded C42 action representation**.
`runtime.c` retains its nominal LT edge, branch endpoints, map cardinality and
original Acc/LT values. General witness/action equivalence and serialized source
maps are not provided. Step's reconstruction of the original immutable Acc fields
uses that captured representation under quotation; this representation choice is
not a generated proof of source equality. Callback/capture construction remains
manual in `support.c`, and zero-down retains refusal for impossible foreign input.

The selected complete Core must match the supplied admitted successor reference.
The owned Acc Fold retains scrutinee, clause and both indexed endpoints. The LT
Match retains its original fields and two path binders in each branch. The
emitter permits one owned transport of the inspected direction/count per branch
and refuses unsupported body/family/field forms without copying staged output.
No evaluator, query or owner-store mutation occurs during emission. This is a
bounded partial lowerer, not general indexed/callable/Identity selection.

```sh
sh src/prototype/c_backend/acc_actions/check.sh EMITTER POINTER IMAGE C41_PRODUCTS CORE_ORACLE OUTPUT
```

The fixture imports the actual provider, plus an exact successor alias and an
admitted different successor. The latter remains a refusal; it is never replaced
by the original body. Existing private `gs_sort` declaration and six qualified
C36-C41 products are unchanged. Ordinary C clients link the composed C and the C
library; producer/tools are needed only for admission/emission/oracle evidence.

Current accepted fc52755b/runtime120 c206 supplies the pinned source image and
Core sorting oracle. See the [C43 handoff](../../../../doc/2026-10-04-C-BACKEND-EPOCH43-HANDOFF.md)
for terminal phase evidence, source deltas, failures and exact hashes.

Nat32/depth256/node65536, additional action allocations, immutable source-valid
borrowed code/context/data/private token lifetime and transactional nonoverlapping
output apply. Overflow guard is inspected, not exercised; SAN is finite. Arbitrary
types/comparator closures, broader refinement equivalence, general Identity and
main-backend native indexed/callable Acc remain open. No source checker/erasure,
producer/schema/ABI authority, accepted adoption, actual cost or full Goal claim.
