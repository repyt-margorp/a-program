# Actual Acc creation saved-image command

This bounded command reads one admitted saved image, emits all seven actual
Acc QuickSort bodies plus the complete map/endpoint/frame/down/LT prior-result
recipe and produces ordinary source, object or archive products. The algorithm
retains actual Acc/down recursion, indices, partition and captured parameters.
The [readable C module](../acc_create/example/component.c) and
[declarative header](../acc_create/example/component.h) match every product.
The [actual fixture](../acc_actions/fixture.p) names the source selections.

LT creation validates source-selected prior/result indices before allocation.
Only the immediate prior is checked; the entire borrowed immutable graph remains
a caller/target precondition. Concrete storage/role values/closures/Nat-LT/array
interpretation, full checked Scope/source equivalence and general indexed/callable
native Acc/QuickSort remain unproved. This is a fixed actual-source candidate,
not an alternate sorter, arbitrary Native LinkerScript lowering, source checking
or an erasure policy. Three separately admitted unsupported LT forms stay explicit
refusals. No .a/producer/schema/public ABI or accepted-source change.

Build serially against an explicitly qualified producer tree:

```sh
make -j1 -f src/prototype/c_backend/acc_create_command/build.mk \
  OVERLAY=/absolute/qualified/tree BUILD=/absolute/owned/build \
  CFLAGS='-std=c11 -Wall -Wextra -Werror -O2' \
  /absolute/owned/build/c-acc-create-image
python3 src/prototype/c_backend/acc_create_command/compose.py \
  /absolute/actual-materialized.a /absolute/new-product \
  --driver /absolute/owned/build/c-acc-create-image --product archive --cflag=-O2
cc -std=c11 -I/absolute/new-product ordinary_client.c \
  /absolute/new-product/library.a -o ordinary_client
```

Source is the default product; object supplies component.o, archive library.a.
All include component.c/component.h/section provenance/product.json, expose only
gs_sort and preserve its ABI. The command admits source selections through
existing public APIs, then checks source-owner payload/index/container inertness
and prohibits source advancement while emitting. Fresh bodies supply algorithms;
the reviewed intermediate stages qualify bytes only. Native and legacy images
are separately qualified; no old-image compatibility or query-trial adoption.

Destinations must be new. Private disk staging/anonymous streams and Linux
renameat2(RENAME_NOREPLACE) preserve prior directories/symlinks and clean only
this invocation's files on failure. This is atomic visibility, not crash durability.
Compiler TMPDIR may point to owned disk storage. Command status0 success/1 rejected
or compiler failure/2 I-O/3 pending/4 unsupported remain. Runtime status1-6,
Nat32/depth256/node65536/borrowed immutable/nonoverlap/private-token lifetime and
transactional output remain. Finite SAN is not arbitrary pointer proof; output
overflow guard and larger validation/net costs remain unmeasured/unproved.
