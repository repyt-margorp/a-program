admitted Acc QuickSort. Seven source-derived bodies preserve its partition, pivot
append, two folded-down recursive calls, indices and captures. It is not an
alternate sorter or a general native-backend success. Only `gs_sort` is public;
the unchanged declarative header supports ordinary source/object/archive clients.

This epoch replaces manually numbered frame assignments with positions read from
the selected admitted parameter/Fold/callback/constructor binders. Existing Fold
receipts and induction contexts locate parameter, proof, current index, raw down
and folded IH; actual callback lambdas locate argument and LT edge; actual3/5 branch
lambdas locate constructor fields and two paths. All positions must occur uniquely
in the admitted destination context, and both paths must agree with the boundary.
Full ordered maps and exact nominal endpoint projections remain source-derived.

Target role values, action/closure representation, Nat32/storage/array staging and
complete checked Scope/source equivalence remain explicitly hand-authored or
unproved. The reader borrows admitted source, issues no typing and runs no source
evaluation/WHNF/substitution/typed-query advancement. Descriptive context tokens
are not Scope certificates. The package is a fixed composition of pinned body
products and descriptor bytes, not a compiler accepting arbitrary images.

qualified overlay. `check.sh` takes emitter, materialized image, exact C44 products,
retained Core-case source, qualified pointer interpreter and a new output directory.

endpoint/action refusals and new foreign-frame/unknown-role/unselected-field
refusals. Sanitizers cover the full emitter/inspector/module/client source/object/
archive; reused pointer/Core inputs remain O2. Private raw controls create no new
admitted source or effect policy. Historical native Acc refusal remains explicit.
